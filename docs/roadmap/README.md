## Estado actual

SNTO Alpine está en `0.1.0.dev0`: pipeline de doble temporada implementado,
53 activos visibles, NDSI real parcial (43/53), pendiente para 53/53, CI verde,
sin despliegue propio y sin validación de campo.

La prioridad es consolidar un prototipo reproducible, después aumentar la
fidelidad geográfica, completar la serie invernal, sustituir proxies
territoriales y ejecutar una campaña de campo antes de afirmar validación.
